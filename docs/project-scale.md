# Project Scale

Island Song was built as a Purdue University Fort Wayne senior capstone project across CS 46000 and CS 46500.

## Timeline And Team

- Duration: 32-week two-semester capstone sequence.
- Team size: 6 graduate students.
- Engine: Unreal Engine 5.
- Primary development style: Blueprint-heavy gameplay logic with supporting systems and infrastructure.
- Version control: Perforce P4 / P4V for the production project.

## Product Scope

The final report describes Island Song as a free-to-play puzzle adventure game with a low-poly art style and original soundtrack. The final feature set included:

- Collectables.
- Unlockable doors.
- Multiple challenge and puzzle areas.
- Save/load support.
- Tutorial flow.
- NPC dialogue.
- Cutscenes.
- Original music.
- Functional menus.
- Standalone playable Windows build.

## Testing

The project combined internal testing with external alpha playtesting:

- Internal testing matrix: 42 tracked test cases across puzzles, movement, collectables, and challenges.
- External playtesting workbook: 173 observations from 13 playtesters.
- Feedback analysis report: peer, faculty, and guest feedback was converted into presentation and product action items.
- Jira backlog export: 267 tracked issues, including 150 stories, 77 subtasks, 28 tasks, and 12 epics.

The final report cites 13 external playtest participants whose feedback was turned into game improvements.

# Technical Leadership

Island Song was a two-semester graduate capstone project with a 6-person team, a real client relationship, formal course deliverables, and a playable Unreal Engine release target. My role sat at the intersection of project management and technical architecture.

## Responsibilities

- Served as project manager and technical lead.
- Helped coordinate sprint planning, scope control, and delivery priorities.
- Researched the project tech stack, including Unreal Engine workflows, Perforce, IDE/editor choices, hosting options, CI/CD, and release tooling.
- Kept the team's Perforce infrastructure available and recoverable while teaching the rest of the team how to use P4V, minimizing ramp-up time.
- Designed standards for Unreal input actions and key binding conventions.
- Implemented world partitioning so team members could work on separate portions of the game world with fewer asset conflicts.
- Built and maintained the Windows installer path and supported a website that hosted the game installer.
- Supported optimization and late-stage bug fixing with visual debuggers, GPU profiling, and widget analysis.

## Leadership Constraints

The project had several constraints that made the technical leadership work more important:

- Most gameplay logic lived in Unreal Blueprints, where merges are much harder than text-based source control.
- The team was new to P4V and Unreal production workflows.
- The project contained large binary assets and multi-gigabyte deliverables.
- The infrastructure path had to work around network restrictions and older hardware.
- The team needed a stable workflow without spending thousands of dollars on vendor-managed hosting.

## Outcome

The team shipped a complete playable game experience, exceeded the course hour target, produced a polished final package, and was recognized as PFW's best capstone project. My work helped keep the team's development pipeline functioning while also contributing directly to game systems, optimization, installer distribution, and release readiness.

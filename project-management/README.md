# Project Management Artifacts

This folder contains selected planning, workflow, and validation artifacts from the Island Song capstone archive.

## Included Files

- `Style Guide.docx` - Unreal asset, Blueprint, file, and naming conventions for the team.
- `Team Roles Responsibilities Policies.docx` - roles, responsibilities, communication rules, meeting expectations, budget policy, and team decision process.
- `engineering-decisions/Initial Meeting Notes - Version Control Cost Analysis.docx` - early cost and workflow analysis comparing Perforce, GitHub, GitLab, and hosting options.
- `Time Effort Log.xlsx` - detailed team hour log used to generate the production evidence dashboard in the root README.
- `Jira Backlog Export.xlsx` - Jira export with 267 tracked issues from the project.
- `testing/Internal Testing Matrix.xlsx` - internal test cases across major gameplay systems.
- `testing/External Playtesting Log.xlsx` - external playtesting observations and team responses.
- `Feedback Analysis Report.docx` - peer, faculty, and guest feedback analysis with action plans.

These files are included because they show the professional structure behind the project: team standards, version-control research, sprint/task tracking, testing, playtesting, and feedback loops.

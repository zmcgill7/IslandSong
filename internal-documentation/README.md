# Internal Documentation

This folder contains team-facing documentation used to explain and maintain major Island Song systems.

Included topics:

- Color mechanic
- Player system
- UI design
- World and map
- Music
- Settings
- Puzzle systems, including keys, percussion, strings, and shared puzzle documentation

These documents were pulled from the project archive because they show how the team documented Blueprint-heavy Unreal systems for collaboration, onboarding, and maintenance.

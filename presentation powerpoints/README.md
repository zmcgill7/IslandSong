# Presentation PowerPoints

This folder contains selected Island Song presentation decks from the capstone sequence.

Included decks:

- Project proposal presentation
- Q1 midterm presentation
- Q4 final presentation, compressed from the original multi-gigabyte deck by recompressing embedded videos and oversized images

The original decks contained high-quality video and image assets, which made the archive very large. The final presentation included here is compressed for GitHub while preserving the deck as an editable PowerPoint artifact.
